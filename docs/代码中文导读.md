# 代码中文导读

本文按目录说明服务端代码职责，帮助从启动入口逐层阅读。关键 Go 文件在包说明文件（`doc.go`）和函数附近标注中文注释。

## 启动入口

万象后端由四个服务组成，对应四个独立入口，另有一个聚合入口统一编排：

- `cmd/wanxiang`：**聚合入口**（单进程）。在一个进程内通过 `internal/app.Supervise` 同时启动四个服务，每个服务运行在独立 goroutine 中，panic 被 `recover` 隔离，失败后按指数退避自动重启。适合日常「一条命令拉起全部」。
- `cmd/web-server`：设备端 HTTP API（换票 + 设备登记）。
- `cmd/admin-server`：管理 API 和静态管理网页，并初始化管理员。
- `cmd/websocket-server`：WebSocket 转发服务。
- `cmd/scrcpy-server`：通过 adb 部署并桥接 scrcpy 的 H.264 视频与控制流。

这四个 `cmd/*/main.go` 都是**薄壳**：只调用 `internal/app` 中对应的 `Run*` 函数并处理致命错误。服务的完整装配与生命周期逻辑集中在 `internal/app` 包，可被聚合入口复用：

| 入口 | 委托函数 | 端口（默认） |
| --- | --- | --- |
| `cmd/wanxiang` | `app.Supervise`（编排下面四个 `Run*`） | 全部 |
| `cmd/web-server` | `app.RunWeb` | `:9001` |
| `cmd/admin-server` | `app.RunAdmin` | `:9002` |
| `cmd/websocket-server` | `app.RunWebsocket` | `:9003` |
| `cmd/scrcpy-server` | `app.RunScrcpy` | `:9004` |

建议先看 `internal/app/supervise.go`（编排与重启机制）和 `internal/app/{web,admin,websocket,scrcpy}.go`（各服务装配），再进入下面的 `internal` 包。

## 内部模块

- `internal/app`：服务的装配与单进程编排。`Supervise` 提供 goroutine 隔离 + `recover` 兜底 + 指数退避自动重启；`RunWeb`/`RunAdmin`/`RunWebsocket`/`RunScrcpy` 分别封装四个服务的启动与优雅关闭。
- `internal/envfile`：读取 `KEY=value` 配置；已有系统环境变量优先。
- `internal/logic`：登录、密码哈希、用户创建、设备登记和 WebSocket 临时票据等业务规则。
- `internal/storage/sqlite`：数据库连接、表结构与迁移、用户/设备/分组/会话等数据访问。
- `internal/scrcpy`：ADB 封装、scrcpy 协议、视频/控制流桥接、群控同步与 APK 的 AXML 包名解析。
- `internal/transport/webapi`：设备端 HTTP 路由，无认证，凭 deviceId 换一次性票据并登记设备。
- `internal/transport/adminapi`：管理端 HTTP 路由、Bearer 认证和管理 API 请求处理。
- `internal/transport/websocket`：设备和管理端连接、消息转发、设备控制以及 `com` 命令协议。

## `com` 命令示例

管理页面约每 25 秒发送一次心跳：

```json
{"type":"com","command":"ping","requestId":"ping-1","data":{"sentAt":1731670000000}}
```

服务端在 `commands.go` 中按命令白名单分发，响应会保留请求编号：

```json
{"type":"com","command":"pong","requestId":"ping-1","data":{"sentAt":1731670000000}}
```

后续扩展命令时，先定义命令名和专用数据结构，再在分发 `switch` 中增加明确处理逻辑，并为正常、错误输入补测试。会改变设备或用户状态的命令还必须增加身份、权限和会话校验。

## 日志与测试

- Go 服务的运行日志输出到启动服务的控制台；聚合模式下统一写入 `logs/wanxiang.log`，分离模式下写入 `logs/<service>.log`。浏览器端 WebSocket 心跳日志可在开发者工具 Console 中查看。
- 在仓库根目录运行 `go test ./...` 执行 Go 测试；运行 `go vet ./...` 检查常见静态问题。
