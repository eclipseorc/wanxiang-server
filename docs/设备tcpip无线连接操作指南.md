# 设备 tcpip 无线连接操作指南

> 本文是**运维操作手册**，回答一个问题：**拿到一台共享测试设备，怎么把它接入远程控制，以及设备重启后怎么恢复。**
>
> 技术背景与方案论证见《设备无线接入方案.md》。本文只讲"照着做"，不含论证。

---

## 一句话结论

每台设备**首次插一次 USB 线**切到 `tcpip 5555`，之后只要设备不重启，**全程无线、免配对、免点手机**；设备每次重启后，**再插一次 USB 线重新切一次**即可。

---

## 为什么用 tcpip 5555（而不是无线调试配对）

| | 无线调试（配对码） | tcpip 5555（本方案） |
| --- | --- | --- |
| 首次接入 | 无线配对，填 6 位码 | 插一次 USB 线 |
| 日常连接 | 端口随机变，易掉授权 | 固定 5555，直接 `IP:5555` |
| 设备重启后 | 端口+授权全失效，要点手机 | 需再插一次 USB 重新切 |
| 依赖第三方 App | 无 | 无 |

**取舍**：tcpip 5555 在"两次重启之间"完全免碰设备，代价是"每次重启后插一次 USB"。对需要经常重启的共享设备，这比"每次重启都要在手机上点无线调试 + 填配对码"省事得多，且不引入任何第三方 App。

---

## 前置条件

- 设备已**开启开发者选项**（设置 → 关于手机 → 连点「版本号」7 次）
- 设备已**开启 USB 调试**（开发者选项 → USB 调试）
- 设备通过 USB 线连到运行后端（wanxiang-server）的电脑
- 设备与后端电脑**同一局域网**，且设备 IP 可获取

---

## 操作流程

### 一、首次接入（每台设备一次）

1. 手机开 USB 调试，插 USB 线连到后端电脑。手机上若弹「允许 USB 调试」授权框，点「允许」。
2. 打开管理后台，找到该设备，点「**远程控制**」。
3. 在远程控制窗口里，点顶部「**传统模式**」标签。
4. 第 1 步「切换为无线」：
   - 下拉框选到该设备的序列号（若为空，点右侧刷新按钮重新检测）。
   - 端口保持默认 `5555`。
   - 点「**切换为无线**」。这一步在后台执行 `adb tcpip 5555`。
5. **拔掉 USB 线**。
6. 第 2 步「连接设备」：
   - 填设备 IP。
   - 端口保持 `5555`。
   - 点「**连接**」。这一步执行 `adb connect IP:5555`。
7. 第 3 步「开始控制」进入远程画面。

**之后**：关窗重开、后端重启、电脑重启，都能自动恢复，**设备不用再碰**。

### 二、设备重启后恢复（每次重启一次）

设备重启会导致 tcpip 模式失效（退回 USB 模式），需重新切一次：

1. 插 USB 线连到后端电脑。
2. 打开「远程控制」→「传统模式」。
3. 第 1 步「切换为无线」：选序列号 → 点「切换为无线」。
4. 拔线。
5. 第 2 步「连接设备」：填 IP → 点「连接」。

> 提示：设备 IP 若因路由器重新分配而变化，先到设备 Wi-Fi 设置里确认当前 IP，再填入。

## 常见问题

### Q1：第 1 步下拉框检测不到设备序列号？

- 确认 USB 线已插好、设备已开「USB 调试」、手机上已点「允许 USB 调试」。
- 点下拉框右侧的刷新按钮重新检测。
- 若仍为空，换一根 USB 线（部分线材只供电不传数据）。

### Q2：点「切换为无线」报错？

- 最常见是设备未授权：手机上重新点「允许 USB 调试」，再试一次。
- 确认设备没有锁屏（锁屏状态下 adb tcpip 可能无法执行）。

### Q3：第 2 步「连接」报「设备未连接 / unauthorized」？

- 确认设备 IP 正确，且设备与后端电脑同一局域网。
- 确认第 1 步「切换为无线」已成功执行（成功后设备监听 5555）。
- 若提示 unauthorized，通常是 USB 授权丢失，重新插线点「允许」后再切一次。

### Q4：为什么不能做到"重启后零人工"？

Android 安全模型规定：`adb tcpip` 切换的监听端口在设备重启后会被清除，退回 USB 模式。未 root 时，没有任何 App 或方案能绕过"重启后需重新切 tcpip"这一步（详见《设备无线接入方案.md》§2）。

## 与"无线调试（配对）"模式的关系

本系统**同时保留两种模式**（远程控制窗口顶部的模式切换）：

- **传统模式（tcpip 5555）**：本指南所述，适合需要经常重启、追求"两次重启间免碰设备"的设备。
- **无线调试模式**：适合有「无线调试」菜单、且不常重启的设备，纯无线配对接入。

两种模式可混用：设备走哪套，取决于它的重启频率和你是否方便插 USB。
