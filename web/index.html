远程控制

尚未连接

通过 ADB 无线调试连接设备。设备需在「开发者选项 → 无线调试」中开启并显示配对信息。

填写无线调试页的配对端口与 6 位配对码。
配对成功后，用连接端口建立 ADB 连接。
连接就绪后，点击开始进入远程画面。

适用于没有「无线调试」菜单的 Android 11 及更早设备。先用 USB 线连接电脑并开启「USB 调试」，在下方填写设备序列号后点「切换为无线」，然后拔线，用手机 IP + 端口连接。

切换成功后，用下方「设备 IP + 端口」建立连接。
用手机 IP 与端口建立 ADB 连接（无需配对码）。
连接就绪后，点击开始进入远程画面。
