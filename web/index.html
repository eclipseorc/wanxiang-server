05 / Device Management

设备权限设置

配置设备的系统权限与限制策略，保存后下发到所有已纳管（Device Owner）设备

网络与连接

限制设备对网络、热点、蓝牙等连接能力的使用

禁止启用 WiFi
开启后，员工的手机设备将禁止启用 WiFi
禁止启用热点
开启后，员工的手机设备将禁止启用热点
禁止启用蓝牙
开启后，员工的手机设备将无法自行启用蓝牙
禁止开启 VPN
开启后，员工的手机设备将强制屏蔽 VPN 功能，无法开启 VPN 服务
禁止开启飞行模式
开启后，员工的手机设备将禁止开启飞行模式
移动网络限制
禁止开启移动网络后，员工的手机设备将强制关闭移动网络开关，员工无法自行开启；禁止关闭移动网络后，员工的手机设备将强制开启移动网络开关，员工无法自行关闭
WIFI 白名单设置
添加允许设备连接的 WiFi（SSID），未配置则不限制

系统与硬件

限制设备对系统能力与硬件组件的使用

禁止开启 USB 调试 / 开发者模式
开启后，员工的手机设备无法自行启用开发者模式并强制关闭 USB 调试功能
禁止使用 USB 传输文件
开启后，员工的手机设备将无法自行使用 USB 传输文件
禁止启用摄像头
开启后，员工的手机设备将禁止启用摄像头
禁止截屏权限
开启后，员工的手机设备将无法自行截屏
禁止恢复出厂设置
开启后，员工的手机设备将无法自行恢复出厂设置
是否开启屏幕常亮
开启后，员工的手机设备屏幕将保持常亮状态
设置锁屏显示的单位名称
显示在锁屏界面的组织/单位名称
